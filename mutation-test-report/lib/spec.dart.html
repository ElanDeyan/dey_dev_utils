       6 /// The Specification Pattern: compose business rules as reusable, testable predicates.
       7 ///
       8 /// A Spec represents a single business rule that an object either satisfies or doesn't.
       9 /// Instead of embedding validation logic directly in methods, specifications are
      10 /// first-class objects that can be created, combined, tested, and reused independently.
      11 ///
      12 /// This pattern is ideal for:
      13 /// - **Domain rules**: Entity validation, filtering, and search criteria
      14 /// - **Reusability**: The same rule applies in multiple contexts without duplication
      15 /// - **Testability**: Each rule is isolated and easy to unit test
      16 /// - **Composability**: Combine simple rules into complex business logic
      17 /// - **Readability**: Express business intent clearly through method names
      18 ///
      19 /// Compose specs using:
      20 /// - `&` / [and] — Both must be satisfied (AND logic)
      21 /// - `|` / [or] — At least one must be satisfied (OR logic)
      22 /// - `^` / [xor] — Exactly one must be satisfied, not both (XOR logic)
      23 /// - [toNegated] — Inverts the rule (NOT logic)
      24 ///
      25 /// **Creating a Spec:**
      26 /// ```dart
      27 /// /// Business rule: person is old enough to vote
      28 /// class IsEligibleVoter extends Spec<Person> {
      29 ///   @override
      30 ///   bool isSatisfiedBy(Person person) => person.age >= 18;
      31 /// }
      32 ///
      33 /// /// Business rule: person has valid contact info
      34 /// class HasValidEmail extends Spec<Person> {
      35 ///   @override
      36 ///   bool isSatisfiedBy(Person person) => person.email.contains('@');
      37 /// }
      38 /// ```
      39 ///
      40 /// **Using a Spec:**
      41 /// ```dart
      42 /// // Single rule
      43 /// final isVoter = IsEligibleVoter();
      44 /// if (isVoter.isSatisfiedBy(person)) {
      45 ///   registerToVote(person);
      46 /// }
      47 ///
      48 /// // Composed rules
      49 /// final validVoter = IsEligibleVoter() & HasValidEmail();
      50 /// final voters = people.where((p) => validVoter.isSatisfiedBy(p)).toList();
      51 ///
      52 /// // Complex compositions
      53 /// final canReceiveNewsletter = HasValidEmail() & (IsEligibleVoter() | HasOptedIn());
      54 /// ```
